## 二、架构亮点

### 2.1 多格式模型处理架构
`backend/core/formats/` 实现了工厂模式的多格式处理器：

```text
backend/core/formats/
├── base.py              # FormatHandler 基类
├── yolo_handler.py      # YOLO .pt 格式
├── onnx_handler.py      # ONNX 格式
└── openvino_handler.py  # OpenVINO 格式
```

特性：运行时自动选择最优格式；统一接口 FormatHandler；支持格式转换和导出。

### 2.2 推理流水线架构
`inference.py` 中的双线程流水线：

```text
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ _inference_worker│ →  │  _encode_worker │  →  │  WebSocket 推送  │
│   (推理线程)      │     │  (JPEG 编码线程) │     │   (前端渲染)     │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

 
- 推理与编码分离，避免阻塞 
- 动态 JPEG 压缩质量自适应 
- 视频抽帧策略 
- 实时 FPS 显示 

### 2.3 规则引擎执行器
`executor.py` 实现的执行模型：

```text
# Kahn 拓扑排序：确保依赖节点先执行
sorted_nodes = topological_sort(nodes, edges)

# 层内并行执行：同一层的节点可以并发
for layer in layers:
    await asyncio.gather(*[execute_node(n) for n in layer])
```

端口类型：ANY / IMAGE / BBOX / MASK / SCORES / TRIGGER / CONTROL / MODEL / INT / FLOAT / BOOLEAN / STRING / ARRAY / OBJECT

### 2.4 统一数据目录
2026-05 重构将所有数据统一到 `data/` 目录：

```text
data/
├── datasets/             # 训练数据集 (YOLO 格式)
├── checkpoints/          # 模型权重文件
├── model_cache/          # 模型缓存
├── inference_output/     # 推理结果图片
├── runs/                 # YOLO 训练输出
│   ├── detect/          # 推理结果
│   └── train/           # 训练输出
└── database/            # SQLite 数据库
```
