# CogniFlow 系统托盘功能设计
Windows 系统托盘功能，支持在后台运行并通过托盘图标管理应用

---

## 一、概述
为 CogniFlow 实现 Windows 系统托盘功能，支持在后台运行并通过托盘图标管理应用。

## 二、行为定义
        
| 动作 | 行为 |
| --- | --- |
| 应用启动 | 自动打开浏览器访问 WebUI，同时创建系统托盘图标 |
| 双击托盘图标 | 打开浏览器窗口 |
| 右键 → "打开浏览器" | 同上 |
| 右键 → "退出" | 退出应用程序 |

## 三、技术方案

### 3.1 依赖

 
- `pystray`：系统托盘实现 
- `Pillow`：图标图像处理 
- `webbrowser`：浏览器打开 

### 3.2 文件结构

```text
CogniFlow/
├── system_tray/
│   ├── __init__.py
│   ├── tray_manager.py    # 托盘管理、菜单、事件处理
│   └── browser.py        # 浏览器打开逻辑
```

### 3.3 托盘菜单

 
- "打开浏览器" — 打开默认浏览器访问 http://localhost:8000 
- 分隔线 
- "退出" — 退出应用程序 

### 3.4 入口修改
修改 `app.py`：

 
- 添加托盘初始化逻辑 
- 启动时自动打开浏览器 
- 启动托盘事件循环
