CogniFlow Logo 实施方案

SVG 文件创建、favicon 替换 | 日期: 2026-05-01

文件清单

文件路径操作说明
webui/public/logo.svg创建主 Logo（256x256，带渐变）
webui/public/favicon.svg创建Favicon（32x32，纯色）
webui/index.html修改更新 favicon 引用

实施步骤

Task 1: 创建主 Logo SVG

文件：创建 webui/public/logo.svg

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 256 256">
  <defs>
    <linearGradient id="cfGradient" x1="0%" y1="100%" x2="100%" y2="0%">
      <stop offset="0%" stop-color="#8B5CF6"/>
      <stop offset="100%" stop-color="#00D4FF"/>
    </linearGradient>
  </defs>

  <!-- C 形（左侧半圆环） -->
  <path d="M 80 48 A 80 80 0 1 0 80 208"
        fill="none" stroke="url(#cfGradient)"
        stroke-width="24" stroke-linecap="round"/>

  <!-- F 形（右侧方形框架） -->
  <path d="M 176 48 L 176 64 L 112 64 L 112 112
           L 160 112 L 160 128 L 112 128 L 112 192 L 176 192"
        fill="none" stroke="url(#cfGradient)"
        stroke-width="24" stroke-linecap="round" stroke-linejoin="round"/>

  <!-- 连接节点（中心交叠处） -->
  <circle cx="128" cy="128" r="12" fill="#00D4FF"/>
  <circle cx="108" cy="108" r="8" fill="#8B5CF6"/>
  <circle cx="148" cy="148" r="8" fill="#00D4FF"/>
</svg>

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32">

Task 3: 更新 index.html

文件：修改 webui/index.html

将 <link rel="icon" type="image/svg+xml" href="/vite.svg" /> 替换为：

<link rel="icon" type="image/svg+xml" href="/favicon.svg" />

Task 4: 验证与提交

# 验证文件存在性
ls -la webui/public/logo.svg webui/public/favicon.svg

# 提交更改
git add webui/public/logo.svg webui/public/favicon.svg webui/index.html
git commit -m "feat(webui): 添加 CogniFlow 专业 Logo 和 Favicon"
