CogniFlow WebUI 升级设计方案

WebUI + 训练图集管理 + 模型管理 + 数据标注 | 日期: 2026-04-11

一、需求概述

对 CogniFlow 项目进行 WebUI 升级，实现以下功能：

  • WebUI — FastAPI + Vue3 全栈界面
  • 训练图集管理 — 按目录管理图片分组
  • 模型管理 — 完整管理（版本、元数据、指标）
  • 数据标注交互 — 通过 WebUI 进行实时标注
  • 模型启动 — 加载模型后手动控制开始

二、技术选型

层级技术说明
后端框架FastAPI + Uvicorn高性能异步 API
数据库SQLite + SQLAlchemy单用户场景足够
实时通信WebSocket训练状态实时推送
前端框架Vue3 + Vite + TypeScript现代前端栈
UI 组件库Element PlusVue3 组件库
状态管理PiniaVue3 官方推荐
图片存储本地文件系统按配置路径存储

部署架构：FastAPI 同时托管 Vue3 构建产物（前后端合一）

六、核心功能流程

6.1 图集管理流程

  1. 创建图集（名称 + 描述）
  2. 上传图片到图集（支持拖拽批量）
  3. 图片按目录自动分组
  4. 查看图集图片网格
  5. 删除图片或整个图集

6.2 标注流程

  1. 进入标注页面
  2. 选择图片（从图集选择或上一张/下一张）
  3. 绘制 Bounding Box（鼠标拖拽）
  4. 按数字键 1-9 选择类别
  5. 按 S 保存标注
  6. 按 Z 撤销上一个框
  7. 自动切换下一张图

6.3 训练流程

  1. 选择模型（已有模型或新建）
  2. 选择训练图集
  3. 配置超参（学习率、batch_size 等）
  4. 启动训练
  5. WebSocket 实时接收训练状态
  6. 查看 loss 曲线
  7. 可暂停/停止训练

6.4 模型启动流程

  1. 选择已训练模型
  2. 加载模型（初始化推理 pipeline）
  3. 初始化游戏环境
  4. 等待用户手动开始
  5. 用户触发开始后执行推理循环
  6. 实时显示推理结果

九、数据库 Schema SQL

CREATE TABLE atlas (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE category (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) NOT NULL UNIQUE,
    color VARCHAR(7) DEFAULT '#FF0000'
);

CREATE TABLE image (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    atlas_id INTEGER NOT NULL,
    file_path VARCHAR(500) NOT NULL,
    directory VARCHAR(255),
    width INTEGER,
    height INTEGER,
    annotated BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (atlas_id) REFERENCES atlas(id) ON DELETE CASCADE
);

CREATE TABLE annotation (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    image_id INTEGER NOT NULL,
    category_id INTEGER NOT NULL,
    bbox JSON NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (image_id) REFERENCES image(id) ON DELETE CASCADE,
    FOREIGN KEY (category_id) REFERENCES category(id) ON DELETE CASCADE
);

CREATE TABLE model (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(255) NOT NULL,
    version VARCHAR(50),
    file_path VARCHAR(500),
    atlas_id INTEGER,
    metrics JSON,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_best BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (atlas_id) REFERENCES atlas(id) ON DELETE SET NULL
);

CREATE TABLE training_job (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    model_id INTEGER NOT NULL,
    atlas_id INTEGER NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    config JSON,
    current_step INTEGER DEFAULT 0,
    total_steps INTEGER,
    metrics JSON,
    started_at TIMESTAMP,
    finished_at TIMESTAMP,
    FOREIGN KEY (model_id) REFERENCES model(id) ON DELETE CASCADE,
    FOREIGN KEY (atlas_id) REFERENCES atlas(id) ON DELETE CASCADE
);

十、备注

  • 图片实际存储在本地文件系统，数据库只存储路径
  • 标注格式使用 COCO Bounding Box [x, y, w, h]
  • WebSocket 心跳间隔 30 秒
  • 训练检查点保存间隔可配置
