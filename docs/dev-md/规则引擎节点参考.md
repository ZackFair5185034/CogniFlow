| 分类 | 节点数 | 功能 | 颜色 |
| --- | --- | --- | --- |
| input | 8 | 触发 + 数据采集（触发器 5 + 采集 3） | 绿色 |
| detection | 3 | 目标检测模型推理 | 青色 |
| processing | 4 | 数据变换与增强 | 黄色 |
| action | 5 | 外部操作执行（键盘/鼠标/HTTP 等） | 橙色 |
| logic | 8 | 流程控制 + 条件分支 | 紫色 |
| output | 3 | 结果输出/持久化 | 红色 |

## 四、端口类型兼容矩阵
以下矩阵定义了哪种源端口类型可以连接到哪种目标端口类型。类型兼容性是前后端双重校验的——画布上连接时前端校验，执行时后端再次校验。

                    
| 源类型 | 兼容目标类型 |
| --- | --- |
| ANY | 全部 14 种类型（万能桥接） |
| IMAGE | ANY, IMAGE |
| BBOX | ANY, BBOX |
| MASK | ANY, MASK |
| SCORES | ANY, SCORES |
| TRIGGER | ANY, TRIGGER, CONTROL |
| CONTROL | ANY, CONTROL |
| MODEL | ANY, MODEL |
| INT | ANY, INT |
| FLOAT | ANY, FLOAT |
| BOOLEAN | ANY, BOOLEAN |
| STRING | ANY, STRING |
| ARRAY | ANY, ARRAY |
| OBJECT | ANY, OBJECT |

****
 
- 端口类型仅决定是否*允许连接*，不保证运行时数据格式正确 
- `TRIGGER` 输出可连 `CONTROL` 输入，反之不成立（单向兼容） 
- `CONTROL` 仅用于逻辑/动作链串联，不传递业务数据 
- `ANY` 类型是万能桥接，但宽松的连接可能导致运行时类型错误
