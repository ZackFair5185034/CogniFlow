## 四、端口类型兼容矩阵

以下矩阵定义源端口类型可连接到哪些目标端口类型。
端口兼容性是前后端双重校验的——画布连接时前端校验，执行时后端再次校验。

| 源类型 | 兼容目标类型 |
| --- | --- |
| `ANY` | 全部 14 种类型（万能桥接） |
| `IMAGE` | ANY, IMAGE |
| `BBOX` | ANY, BBOX |
| `MASK` | ANY, MASK |
| `SCORES` | ANY, SCORES |
| `TRIGGER` | ANY, TRIGGER, CONTROL |
| `CONTROL` | ANY, CONTROL |
| `MODEL` | ANY, MODEL |
| `INT` | ANY, INT |
| `FLOAT` | ANY, FLOAT |
| `BOOLEAN` | ANY, BOOLEAN |
| `STRING` | ANY, STRING |
| `ARRAY` | ANY, ARRAY |
| `OBJECT` | ANY, OBJECT |

**说明：**

- 端口类型仅决定是否*允许连接*，不保证运行时数据格式正确
- `TRIGGER` 输出可连 `CONTROL` 输入，反之不成立（单向兼容）
- `CONTROL` 仅用于逻辑/动作链串联，不传递业务数据
- `ANY` 类型是万能桥接，但宽松的连接可能导致运行时类型错误
