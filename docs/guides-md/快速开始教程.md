# CogniFlow 快速开始教程
通用视觉感知处理框架，快速启动指南

---

## 一、项目概述
CogniFlow 是一个通用视觉感知处理框架，核心流程：

 
- **图集管理** — 上传、管理训练图片，支持目录组织 
- **数据标注** — YOLO 格式目标检测标注，SVG 边界框绘制 
- **模型训练** — YOLO 模型训练，支持 GPU，实时 mAP 指标 
- **模型推理** — 图片/视频检测，WebSocket 实时流推送 
- **规则引擎** — 可视化流程编排，Kahn 拓扑排序执行器 

## 二、快速开始

### 2.1 启动服务

```text
# 启动后端 (FastAPI)
cd backend
pip install -r requirements.txt
uvicorn app:app --reload --port 8000

# 启动前端 (新终端)
cd webui
pnpm install
pnpm dev
```

访问 http://localhost:5173

### 2.2 创建图集并上传图片

 
1. 点击左侧菜单 **图集管理** 
1. 点击 **新建图集**，输入名称 
1. 进入图集详情，点击 **上传图片** 按钮 

### 2.3 标注数据

 
1. 在图集详情选中一张或多张图片 
1. 点击 **开始标注** 
1. 在标注页面：左侧选择或创建类别（树形目录）；按住鼠标左键拖动绘制边界框 
1. 快捷键：A/D 切换上一张/下一张，W 创建新类别 

### 2.4 训练模型

 
1. 进入 **模型管理** 
1. 点击 **新建模型**，选择绑定的图集 
1. 进入 **模型训练** 页面，选中模型点击 **开始训练** 
1. 训练过程中可查看 loss、mAP 等指标曲线 
1. 训练完成后可 **设为最佳** 

### 2.5 模型推理测试

 
1. 进入 **模型启动** 
1. 选择训练好的模型，点击 **加载模型** 
1. 可选择：**上传图片** 进行图片检测；**上传视频** 进行视频检测（WebSocket 实时推送） 

### 2.6 规则引擎

 
1. 进入 **规则引擎** 页面 
1. **创建规则图**：点击新建，输入名称描述 
1. **查看节点**：访问节点定义列表 
1. **配置规则**：通过 API 或直接编辑 JSON 
1. **执行规则**：保存后点击 **执行** 
**注意：**画布可视化编辑器（拖拽节点、连接端口）正在开发中，当前通过 API 进行配置。

## 三、目录结构

```text
CogniFlow/
├── backend/                 # FastAPI 后端
│   ├── app.py              # 主入口
│   ├── database.py          # SQLAlchemy ORM + SQLite
│   ├── schemas.py           # Pydantic 模型
│   ├── websocket_manager.py # WebSocket 管理
│   ├── routers/            # API 路由
│   │   ├── atlas.py        # 图集管理
│   │   ├── image.py        # 图片管理
│   │   ├── annotation.py    # 标注管理
│   │   ├── category.py      # 类别管理（树形目录）
│   │   ├── model.py        # 模型管理 + 多格式文件
│   │   ├── training.py      # 训练管理 + 进度推送
│   │   ├── yolo_training.py # YOLO 训练核心
│   │   ├── inference.py     # 图片/视频推理（流水线）
│   │   ├── ws_stream.py    # 视频流 WebSocket
│   │   ├── launch.py       # 模型启动（⚠️仅模拟）
│   │   ├── rule_engine.py  # 规则图 CRUD + 执行
│   │   └── websocket.py     # 通用 WebSocket
│   ├── core/
│   │   ├── backends/       # 推理设备自动检测
│   │   ├── formats/       # 多格式处理器 (YOLO/ONNX/OpenVINO)
│   │   └── export/         # 模型导出器
│   └── services/
│       └── rule_engine/    # 规则引擎核心
│           ├── executor.py   # Kahn 拓扑排序执行器
│           ├── graph_manager.py # 图管理
│           ├── registry.py   # 节点注册
│           ├── scheduler.py  # Cron 调度器
│           └── nodes/        # 节点实现
├── webui/                  # Vue3 前端
│   └── COGNIFLOW_DESIGN.md # 设计规范
├── engine/                 # Python 核心包
└── data/                   # 统一数据目录
```

## 四、API 参考

### 图集管理

```text
GET    /api/atlas                 # 获取图集列表
POST   /api/atlas                 # 创建图集
GET    /api/atlas/:id             # 获取图集详情
PUT    /api/atlas/:id             # 更新图集
DELETE /api/atlas/:id             # 删除图集
GET    /api/atlas/:id/images      # 获取图片列表
POST   /api/atlas/:id/images      # 上传图片
POST   /api/atlas/:id/directories # 创建目录
DELETE /api/atlas/:id/images/:imageId # 删除图片
GET    /api/atlas/:id/export-yolo # 导出 YOLO 格式
```

## 五、常见问题
             
| 问题 | 解答 |
| --- | --- |
| 训练中断后能继续吗？ | 可以，训练任务支持断点续传，重新开始训练会自动加载已有进度。 |
| 支持哪些模型格式？ | 支持 YOLO (.pt)、ONNX (.onnx)、OpenVINO 三种格式。 |
| 如何导出模型？ | 在模型详情页点击导出按钮，选择目标格式（onnx/openvino/tensorrt）。 |
| 规则引擎支持循环吗？ | 支持，使用 **循环** 节点，可设置最大迭代次数。 |
| 视频推理如何实时查看？ | 视频推理通过 WebSocket 实时推送检测结果，浏览器自动更新画面。 |
| 如何选择 GPU 训练？ | 在 **模型训练** 页面，点击设备选择器选择 GPU 设备（⚠️ 前端入口开发中）。 |
| 画布编辑器如何使用？ | ⚠️ 可视化拖拽编辑器正在开发中，当前通过 API 进行规则配置。 |
