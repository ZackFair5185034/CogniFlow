# CogniFlow 快速开始教程
通用视觉感知处理框架，快速启动指南

---

## 一、项目概述
CogniFlow 是一个通用视觉感知处理框架，核心流程：

 
- **图集管理** — 上传、管理训练图片，支持目录组织 
- **数据标注** — YOLO 格式目标检测标注，SVG 边界框绘制 
- **模型训练** — YOLO 模型训练，支持 GPU，实时 mAP 指标 
- **模型推理** — 图片/视频检测，WebSocket 实时流推送 
- **规则引擎** — 可视化流程编排，Kahn 拓扑排序执行器 

## 二、快速开始

### 2.1 启动服务

```text
# 启动后端 (FastAPI)
cd backend
pip install -r requirements.txt
uvicorn app:app --reload --port 8000

# 启动前端 (新终端)
cd webui
pnpm install
pnpm dev
```

访问 http://localhost:5173

### 2.2 创建图集并上传图片

 
1. 点击左侧菜单 **图集管理** 
1. 点击 **新建图集**，输入名称 
1. 进入图集详情，点击 **上传图片** 按钮 

### 2.3 标注数据

 
1. 在图集详情选中一张或多张图片 
1. 点击 **开始标注** 
1. 在标注页面：左侧选择或创建类别（树形目录）；按住鼠标左键拖动绘制边界框 
1. 快捷键：A/D 切换上一张/下一张，W 创建新类别 

### 2.4 训练模型

 
1. 进入 **模型管理** 
1. 点击 **新建模型**，选择绑定的图集 
1. 进入 **模型训练** 页面，选中模型点击 **开始训练** 
1. 训练过程中可查看 loss、mAP 等指标曲线 
1. 训练完成后可 **设为最佳** 

### 2.5 模型推理测试

 
1. 进入 **模型启动** 
1. 选择训练好的模型，点击 **加载模型** 
1. 可选择：**上传图片** 进行图片检测；**上传视频** 进行视频检测（WebSocket 实时推送） 

### 2.6 规则引擎
### 2.6 规则引擎

1. 进入 **规则引擎** 页面
1. **创建规则图**：点击新建，输入名称描述
1. **画布编排**：从左侧节点面板（按 6 类折叠）拖拽节点到画布 → 配置参数 → 连接端口（按 14 种端口类型校验）→ 设置变量（支持 `{{var}}` 插值）→ 保存
1. **激活规则**：在规则列表页点击「激活」，按触发器类型（手动 / 定时 / Cron / Webhook / API）自动执行
1. **调试**：底部执行日志面板实时显示每个节点状态（idle→running→success/failed/timeout）+ metrics（key=value 格式）

#### 2.6.1 YOLO 触发节点：输入真实训练类别（Phase 14 起）

`yolo_trigger` / `ObjectExistsCondition` 的 **目标类别** 是 multiselect 控件。
从 Phase 14 起，类别不再硬编码 COCO 7 类，**改为允许自由输入**——

1. 在画布拖入 `yolo_trigger` 节点，先选好 `模型`（model_id）
1. 点击 **目标类别** 控件，可以：
   - **直接键入** 你训练时定义的实际类别名（如 `猫` / `马里奥` / `金币数`），按回车确认
   - **或组合** 已有选项 + 自定义输入
1. 同一规则图里下游的 `ObjectExistsCondition` 节点，**目标类别** 字段应填入相同的中文类别名（与 `yolo_trigger` 的 `class_name` 输出对齐）

> 💡 **类别名必须与训练时完全一致**（含大小写、空格、括号）。例如训练时类别是 `"马里奥"`，yolo_trigger 写 `"mario"` 永远不触发。
> 模型未提供 metrics.categories 时，前端下拉为空，可全部手动输入。

> 画布可视化编辑器（拖拽节点、连接端口、内嵌配置控件）已完整实现。可视化编辑与 API 配置两种方式并存， 多数用户优先使用画布。

## 三、目录结构

```text
CogniFlow/
├── backend/                 # FastAPI 后端
│   ├── app.py              # 主入口
│   ├── database.py          # SQLAlchemy ORM + SQLite
│   ├── schemas.py           # Pydantic 模型
│   ├── websocket_manager.py # WebSocket 管理
│   ├── routers/            # API 路由
│   │   ├── atlas.py        # 图集管理
│   │   ├── image.py        # 图片管理
│   │   ├── annotation.py    # 标注管理
│   │   ├── category.py      # 类别管理（树形目录）
│   │   ├── model.py        # 模型管理 + 多格式文件
│   │   ├── training.py      # 训练管理 + 进度推送
│   │   ├── yolo_training.py # YOLO 训练核心
│   │   ├── inference.py     # 图片/视频推理（流水线）
│   │   ├── ws_stream.py    # 视频流 WebSocket
│   │   ├── launch.py       # 模型启动（⚠️仅模拟）
│   │   ├── rule_engine.py  # 规则图 CRUD + 执行
│   │   └── websocket.py     # 通用 WebSocket
│   ├── core/
│   │   ├── backends/       # 推理设备自动检测
│   │   ├── formats/       # 多格式处理器 (YOLO/ONNX/OpenVINO)
│   │   └── export/         # 模型导出器
│   └── services/
│       └── rule_engine/    # 规则引擎核心
│           ├── executor.py   # Kahn 拓扑排序执行器
│           ├── graph_manager.py # 图管理
│           ├── registry.py   # 节点注册
│           ├── scheduler.py  # Cron 调度器
│           └── nodes/        # 节点实现
├── webui/                  # Vue3 前端
│   └── COGNIFLOW_DESIGN.md # 设计规范
├── engine/                 # Python 核心包
└── data/                   # 统一数据目录
```

## 五、常见问题
             
| 问题 | 解答 |
| --- | --- |
| 训练中断后能继续吗？ | 可以，训练任务支持断点续传，重新开始训练会自动加载已有进度。 |
| 支持哪些模型格式？ | 支持 YOLO (.pt)、ONNX (.onnx)、OpenVINO 三种格式。 |
| 如何导出模型？ | 在模型详情页点击导出按钮，选择目标格式（onnx/openvino/tensorrt）。 |
| 规则引擎支持循环吗？ | 支持，使用 **循环** 节点，可设置最大迭代次数。 |
| 视频推理如何实时查看？ | 视频推理通过 WebSocket 实时推送检测结果，浏览器自动更新画面。 |
| 如何选择 GPU 训练？ | 在 **模型训练** 页面， 通过设备选择器选择 GPU 设备（后端 `/api/training/device-info` 已支持， 前端 Training.vue 设备选择器尚待接入）。 |
| 画布编辑器如何使用？ | 进入 **规则引擎** → 创建/打开规则图 → 左侧节点面板拖拽节点到画布 → 配置参数 → 连线（端口类型不兼容会被拒绝）→ 保存。可参考 `docs/guides-md/规则引擎编辑器使用指南.md`（34 节点完整配置参考 + 10 个测试用例）。 |
