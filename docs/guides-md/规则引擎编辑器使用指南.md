画布操作 · 节点配置参考 · 配置测试用例

## 一、画布编辑器操作指南

### 1.1 界面布局

```text
┌──────────────────────────────────────────────────────────────────┐
│ 工具栏: [←返回] [规则名称] [状态] │ [撤销][重做] │ [WS状态] │ [缩放] │ [网格][吸附][小地图] │ [校验][保存][执行] │
├──────────┬──────────────────────────────────────────┬────────────┤
│ 节点面板  │             画布区域                      │ 变量面板    │
│ (6类折叠) │    从面板拖拽节点到此处                    │  (可折叠)   │
│          │    用鼠标连线连接节点                      │            │
│  ──────── │    滚轮缩放 / 拖拽平移                    │  变量列表   │
│  搜索框   │                                          │  + 添加     │
│          │    选中节点可移动/删除/复制                 │            │
│  INPUT   │    选中连线按 Delete 删除                  │            │
│  DETECT  │                                          │            │
│  PROCESS │    右键节点弹出上下文菜单                  │            │
│  ACTION  │    双击空白处可快速添加节点                 │            │
│  LOGIC   │                                          │            │
│  OUTPUT  │                                          │            │
├──────────┴──────────────────────────────────────────┴────────────┤
│ 底部日志面板: 执行日志 / 结果展示（可折叠，可拖拽调整高度）          │
└──────────────────────────────────────────────────────────────────┘
```

### 1.2 创建和打开规则

 
- **创建新规则**：在规则列表页点击「新建规则」，填写名称和描述后进入编辑器。 
- **打开已有规则**：在规则列表页点击规则卡片，进入编辑器继续编辑。 
- **重命名**：在编辑器顶部直接点击规则名称输入框修改，失去焦点后自动保存。 
- **状态查看**：顶部显示规则当前运行状态（运行中/已停止）。 

### 1.3 添加节点

 
- **从面板拖拽**：左侧节点面板按类别折叠组织，点击展开类别，拖拽节点到画布任意位置。 
- **搜索节点**：面板顶部搜索框输入关键词，实时过滤匹配的节点类型。 
- **自定义标签**：添加后可在节点标题栏修改显示标签，便于区分多个同类型节点。 

### 1.4 配置节点参数
每个节点都有自己的配置面板，直接在节点上操作。系统会根据参数类型自动渲染对应的控件：

             
| 控件类型 | 标识 | 操作方式 | 示例参数 |
| --- | --- | --- | --- |
| **滑块** | slider | 拖拽滑块调节，右侧显示当前数值 | 置信度阈值、IoU、max_age |
| **数字输入** | number | 直接输入数值，可按上下箭头微调 | 最大检测数、延时毫秒、宽度/高度 |
| **下拉选择** | dropdown | 点击展开选项列表，选择一项 | 过滤方式、操作类型、设备 |
| **模型选择** | model-select | 点击展开已注册模型列表，选择模型 | YOLO 检测模型 |
| **文件选择** | file-picker | 点击文件夹图标浏览选择文件 | 模型路径、保存路径 |
| **多行文本** | textarea | 输入多行文本内容 | 类别映射、HTTP Headers |
| **代码** | code | 等宽字体输入区域 | JSON 配置、自定义脚本 |
| **复选框** | checkbox | 勾选/取消 | 启用/禁用选项 |
| **文本输入** | text | 单行文本输入框 | 类别名称、消息模板 |

#### 变量绑定
每个配置项右侧都有一个 **📎** 按钮，点击可弹出变量列表，选择变量后自动插入 `{{变量名}}` 引用。运行时会用实际值替换变量引用。

### 1.5 连接节点

 
- **建立连接**：从节点右侧输出端口（圆点）拖出连线到另一节点左侧输入端口。 
- **端口匹配**：端口会校验类型兼容性，不兼容的端口无法连接。 
- **删除连线**：点击选中连线（高亮），按 Delete 键删除，或右键选择删除。 
- **连接规则**：输出→输入单向连接，不能形成环形依赖（执行引擎按拓扑排序）。 
- **多输出**：一个输出端口可连接多个下游节点（数据分发）。 
- **多输入**：一个输入端口只能接收一个上游连接（数据合并需使用逻辑节点）。 

### 1.6 工具栏功能
               
| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 撤销 | Ctrl+Z | 撤销上一步操作（最多 20 步） |
| 重做 | Ctrl+Y | 重做已撤销的操作 |
| 放大 | Ctrl+滚轮上 | 将画布放大，查看细节 |
| 缩小 | Ctrl+滚轮下 | 将画布缩小，查看全局 |
| 适应画布 | - | 自动缩放使所有节点可见 |
| 网格显示 | - | 切换背景网格显示 |
| 吸附 | - | 移动节点时自动对齐网格 |
| 小地图 | - | 切换右下角缩略图导航 |
| 保存 | Ctrl+S | 保存当前规则图 |
| 校验 | - | 检查规则配置是否正确 |
| 执行 | - | 手动触发一次规则执行 |

### 1.7 右键上下文菜单

 
- **复制**：复制选中的节点到剪贴板 
- **粘贴**：将复制的节点粘贴到鼠标位置 
- **剪切**：剪切选中节点 
- **删除**：删除选中的节点或连线 
- **复制（含配置）**：完全复制节点，保留所有参数配置 

### 1.8 变量管理
右侧变量面板用于管理可在规则中引用的全局变量：

 
- **添加变量**：点击「+ 添加变量」按钮 
- **变量字段**：变量名（字母数字下划线）+ 类型（STRING / NUMBER / BOOLEAN / IMAGE / BBOX） 
- **类型颜色**：STRING=青色, NUMBER=黄色, BOOLEAN=紫色, IMAGE=绿色, BBOX=蓝色 
- **变量引用**：在节点配置中使用 `{{变量名}}` 语法引用 
- **删除变量**：点击变量行末尾的删除按钮 

### 1.9 执行与调试

 
- **手动执行**：点击工具栏「执行」按钮，立即触发一次规则执行。 
- **执行日志**：底部面板实时显示每个节点的执行状态（idle→running→success/failed）。 
- **WebSocket 状态**：顶部工具栏显示 WebSocket 连接状态（已连接/未连接），未连接时执行结果无法实时推送。 
- **结果查看**：执行完成后，底部面板显示每个节点的输出数据。 
- **保存并激活**：规则配置完成后，可在规则列表页激活规则，使其按触发器配置自动执行。

### ▸ LOGIC — 逻辑节点 #DC4FDC

## 四、最佳实践与常见问题

### 4.1 性能优化建议

 
- **减少采集频率**：Camera/VideoCapture 的 fps 和 interval 不要设置过低，建议 fps ≤ 10，interval ≥ 0.5s，避免 CPU/GPU 过载。 
- **适当地使用 Filter**：在 YOLO 检测后接 Filter 节点过滤低置信度结果，减少下游处理压力。 
- **利用并行分支**：无依赖关系的下游节点会并行执行。将耗时操作（如 HttpRequest、SaveResult）与轻量操作（如 LogAction）并列放置。 
- **谨慎使用高帧率跟踪**：TrackerNode 的 min_hits 设置过低（如 1）可能导致大量误检轨迹，建议 min_hits ≥ 3。 
- **SQLite 写操作频率**：SaveResultNode 频繁写入（每秒多次）可能成为瓶颈，建议通过 CounterNode 或 TimerTrigger 控制写入频率。 

### 4.2 常见配置错误
            
| 错误现象 | 原因 | 解决方案 |
| --- | --- | --- |
| 点击执行无任何输出 | 节点未正确连线，或触发器未连接 | 检查规则图是否有至少一个输入节点（ManualTrigger/TimerTrigger 等），并确认连线完整 |
| YOLO 检测结果为空 | 置信度阈值过高，或模型未选择 | 降低 confidence 到 0.25-0.3 测试，确认 model_id 已选择模型 |
| 端口无法连接 | 端口类型不兼容 | 确认输出端口类型与输入端口类型匹配（如 SCORES 不能连接到 IMAGE 端口） |
| 变量绑定不生效 | 变量名拼写错误或变量不存在 | 使用变量面板的「📎」按钮选择变量，避免手工输入拼写错误 |
| 规则保存失败 | 存在孤立节点或未完成的连线 | 使用「校验」功能检查规则图，修复所有校验错误后保存 |
| WebSocket 连接断开 | 网络问题或后端服务重启 | 刷新页面重新连接，检查后端服务状态 |
| HttpRequest 请求失败 | URL 错误或网络不通 | 检查 URL 是否正确，确认目标服务可达，适当增加 timeout 值 |
| Cron 定时不触发 | Cron 表达式错误或规则未激活 | 使用 Cron 校验工具验证表达式格式，确认规则已在列表页「激活」 |

### 4.3 节点限制说明
           
| 限制项 | 最大值 | 说明 |
| --- | --- | --- |
| 单个规则节点数 | 50 | 一个规则图中最多包含 50 个节点 |
| 画布历史步数 | 20 步 | 撤销/重做最多 20 步 |
| 规则变量数 | 30 | 一个规则最多定义 30 个自定义变量 |
| TimerTrigger 最小间隔 | 1 秒 | 定时触发最小间隔，低于此值可能不精确 |
| HTTP 请求超时 | 60 秒 | HttpRequestActionNode 最大超时时间 |
| Tracker 最大轨迹数 | 100 | 同时跟踪的目标数量上限 |
| 单次检测最大目标数 | 1000 | YOLOModel max_detections 最大值 |

### 4.4 调试技巧

 
- **逐步验证**：在构建复杂规则时，先搭建简单链路（如 Input→Output）确认基础连通性，再逐步添加中间节点。 
- **使用 LogAction 调试**：在关键节点后添加 LogAction 节点输出中间数据，帮助定位问题。 
- **观察底部日志面板**：执行日志面板显示每个节点的执行状态和耗时，红色节点表示执行失败。 
- **使用 ManualTrigger 测试**：在配置 Cron/Timer 触发规则前，先用 ManualTrigger 手动测试逻辑正确性。 
- **WebSocket 状态监控**：工具栏的 WS 状态指示灯显示实时连接状态，确保执行结果能推送回前端。 
- **增量保存**：每配置好一个节点或连线后就保存，避免意外丢失配置。
