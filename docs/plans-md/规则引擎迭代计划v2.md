## Phase 10: 端到端可用性 — P0 阻断项

### 10.1 model-select widget 对接模型管理 API ✅ 已完成
**问题：**yolo_model / yolo_trigger 节点的 configSchema 中定义了 `widget: "model-select"`，但前端渲染时仅显示空下拉，未从后端获取模型列表。用户无法选择模型。

**解决方案：**前端架构重构为 Pinia Store 单源模式，Store 新增 `availableModels` + `fetchModels()`，`onMounted` 独立 try-catch 确保模型列表加载不受前置 API 失败影响。RuleNode 通过 `computed(() => store.availableModels)` 读取，空列表时显示提示。

**涉及文件：**

 
- `webui/src/stores/ruleEngine.ts` — 新增 `availableModels` 状态和 `fetchModels()` 方法 
- `webui/src/components/rule-engine/RuleNode.vue` — model-select widget 渲染逻辑，从 Store 读取模型列表 
- `webui/src/views/RuleCanvas.vue` — `onMounted` 独立 try-catch 调用 `fetchModels()` 
- `webui/src/api/` — 使用已有的 `modelApi.list()` 
✅ 验收通过：yolo_model 节点配置下拉展示已训练模型列表，空列表时显示"暂无可用模型"。

### 10.2 执行超时保护
**问题：**当前节点执行没有超时机制。如果某个节点（如 http_request_action 请求外部服务、yolo_model 加载大模型）卡住，整个执行引擎会无限等待。

**涉及文件：**

 
- `backend/services/rule_engine/executor.py` — 在 `_execute_node()` 中添加 `asyncio.wait_for()` 
- `backend/services/rule_engine/nodes/base.py` — BaseExecutor 可选添加 timeout 参数 
**设计要点：**

 
- 全局默认超时：300s（5 分钟），可在执行上下文中覆盖 
- 超时后标记节点为 `failed`，继续执行下游（类似断路器模式） 
- WebSocket 推送 `node_timeout` 事件 
**验收标准：**模拟一个 sleep 超过超时时间的节点，确认执行引擎在超时后继续执行下游节点。

## Phase 11: 可观测性 — P1 重要

### 11.1 节点执行指标采集
**问题：**当前无任何执行指标。无法回答"哪个节点最慢""哪个节点经常失败""一次执行总耗时多少"。

**涉及文件：**

 
- `backend/services/rule_engine/executor.py` — 在 _execute_node 中采集耗时 
- `backend/services/rule_engine/models.py` — ExecutionLog 扩字段 
- `webui/src/views/RuleCanvas.vue` — 执行日志面板展示指标 
**采集指标：**

 
- 节点执行耗时（毫秒级） 
- 节点执行状态（success / failed / timeout） 
- 输入/输出数据量（detections 数组长度等） 
**验收标准：**执行完成后，日志面板能看到每个节点的耗时和执行状态。

### 11.2 image_capture 文件选择器
**问题：**`image_capture` 的 source 字段目前是纯文本输入，用户需要手动输入完整路径或 URL，体验差且易出错。

**涉及文件：**

 
- `webui/src/components/rule-engine/RuleNode.vue` — 新增 file-picker widget 类型 
- `backend/services/rule_engine/nodes/input_nodes.py` — 可能需调整 source 字段的 schema 
**设计要点：**

 
- 新增 widget 类型 `file-picker` 
- 点击后弹出文件选择对话框（使用图集管理的文件选择或浏览器原生 file input） 
- 支持输入 URL 作为备选 
**验收标准：**image_capture 节点可通过文件选择器选择图片路径。
