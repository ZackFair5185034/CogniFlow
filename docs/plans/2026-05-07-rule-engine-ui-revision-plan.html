规则引擎 UI 整改方案

11 个遗留问题分析、P0/P1/P2 修复计划

问题清单与根因分析

P0 — 必须修复（功能阻塞）

1. 左侧节点列表不能展开收纳

根因：nodeCategories 是 computed 属性，每次依赖变化都会重建数组对象，expanded 状态丢失。

方案：将分类状态提取为独立的 reactive 对象，与 computed 分离。

2. 框选功能未实现

根因：flow-container 上的鼠标事件拦截了 VueFlow 的框选逻辑。

方案：移除 @mousedown/@mousemove/@mouseup（仅保留节点拖拽时），使用 SelectionMode.Partial。

3. 右键菜单在节点上未实现

根因：RuleNode.vue 的 @contextmenu.prevent 阻止了所有右键事件冒泡。

方案：移除 @contextmenu.prevent，改为在节点内部通过 @contextmenu 手动 emit。

4. 节点背景色溢出

根因：内部儿童没有裁剪到圆角范围内。

方案：在 .rule-node 上添加 overflow: hidden。

5. Handle 位置不对

根因：Handle 组件需要正确的 offset 属性使其对齐到节点边框。

方案：设置 :offset="0"，确保父容器不裁剪 Handle。

P1 — 重要改进

6. 连接功能不正常

根因：getNodePortType 中 data.inputs/outputs 是数组但使用 handleId 作为 key 查找，需要用 find 匹配。

方案：修改为 ports.find((p) => p.name === handleId || p.label === handleId)

7. 连接颜色设计（Blender 风格）

方案：Handle 根据端口类型获得正确的 CSS 类 :class="['node-handle', `type-${port.type.toLowerCase()}`]"

8. 工具栏重新规划

方案：移除 showGrid 切换（点阵背景默认显示），将 snapGrid 合并到齿轮菜单。

9. 折叠按钮位置不对

方案：将折叠按钮放在 palette-header 的最左侧。

P2 — 体验优化

10. 控制台不可调整高度

方案：在 execution-header 上方添加 4px 高的拖拽条，监听鼠标拖拽事件动态调整面板高度。

11. 收纳宽度适配

方案：使用 computed 动态计算 paletteWidth，execution-panel 的 left 值响应式更新。

验证标准

  • 左侧节点列表可以展开/折叠，刷新页面后状态保持当前画布级别
  • 框选：在画布空白处拖拽出现选择框，松开后选中框内节点
  • 右键菜单：在节点上右键弹出复制/剪切/删除菜单，在空白处右键弹出粘贴/全选菜单
  • 节点圆角不溢出，子元素被正确裁剪
  • Handle 显示在节点左右边框中间位置，鼠标悬浮放大按中心缩放
  • 相同类型端口之间可以连接，不同类型端口拒绝连接并给出 Toast 提示
  • Handle 颜色与其端口类型匹配
  • 工具栏简洁无冗余，功能按钮分组合理
  • 折叠按钮在面板左上方，折叠后面板宽度适配为 48px
  • 控制台面板可拖拽调整高度，有最小/最大限制
  • 面板折叠后，执行日志面板的 left 值随之更新
