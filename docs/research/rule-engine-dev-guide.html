四、节点执行器开发规范

4.1 BaseExecutor 基类

所有节点执行器必须继承 BaseExecutor：

class BaseExecutor(ABC):
    @abstractmethod
    def get_definition(self) -> NodeDefinition:
        """返回节点的完整定义。"""
        pass

    @abstractmethod
    def validate_inputs(self, inputs: Dict[str, Any]) -> tuple[bool, Optional[str]]:
        """校验输入参数。Returns: (is_valid, error_message)"""
        pass

    @abstractmethod
    async def execute(
        self,
        inputs: Dict[str, Any],
        context: ExecutionContext
    ) -> Dict[str, Any]:
        """执行节点逻辑。"""
        pass

4.2 节点注册流程

def init_builtin_executors() -> NodeRegistry:
    registry = NodeRegistry()
    # 输入类
    registry.register(ImageCaptureExecutor())
    registry.register(VideoCaptureExecutor())
    # 检测类
    registry.register(YOLOModelExecutor())
    # 处理类
    registry.register(CategoryEncodeExecutor())
    registry.register(FilterExecutor())
    # 动作类
    registry.register(MouseClickExecutor())
    registry.register(KeyPressExecutor())
    # 逻辑类
    registry.register(ConditionExecutor())
    registry.register(TimerExecutor())
    # 输出类
    registry.register(ActionOutputExecutor())
    registry.register(SaveResultExecutor())
    return registry

4.3 新增节点检查清单

  • 创建执行器类 — 继承 BaseExecutor，实现 get_definition()、validate_inputs()、execute()
  • 注册到 registry.py — registry.register(MyExecutor())
  • 前端节点组件（如需自定义渲染） — 在 components/rule-canvas/nodes/ 创建 .vue 文件
  • 添加单元测试 — 测试 validate_inputs()、execute()、异常处理

五、异常处理规范

5.1 规则引擎异常类

class RuleEngineError(Exception):
    def __init__(self, message: str, details: dict = None):
        super().__init__(message)
        self.message = message
        self.details = details or {}

class CycleError(RuleEngineError):
    """规则图存在循环依赖。"""

class ValidationError(RuleEngineError):
    """规则图校验失败。"""

class ExecutorError(RuleEngineError):
    """节点执行失败。"""
    def __init__(self, message: str, node_id: str = None, node_type: str = None):
        super().__init__(message)
        self.node_id = node_id
        self.node_type = node_type

class ConnectionTypeError(RuleEngineError):
    """节点连接类型不匹配。"""
    def __init__(self, source_type: str, target_type: str):
        message = f"类型不匹配：无法将 {source_type} 连接到 {target_type}"
        super().__init__(message)
        self.source_type = source_type
        self.target_type = target_type

5.2 异常处理原则

场景处理方式
输入校验失败返回 (False, error_message)，不抛异常
执行逻辑失败抛 ExecutorError，记录节点 ID 和类型
环回检测抛 CycleError，包含环节点列表
连接类型不匹配抛 ConnectionTypeError
规则图校验失败抛 ValidationError，包含错误列表

八、代码审查检查清单
