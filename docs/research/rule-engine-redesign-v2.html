Phase A-G 全部完成，包含节点结构设计、配置清单、技术方案与详细实施步骤

一、现状问题

老大原话："规则引擎前端根本没法用，节点没有可配置的东西，节点样式难看"

维度问题
节点可配置性每个节点没有实际参数，config_schema 基本为空
节点样式面板是文字列表，画布节点用 VueFlow 默认样式，缺乏层次感
属性面板表单简陋，无类型化输入
交互体验复制粘贴、撤销重做不完整

二、设计规范

2.1 节点结构（画布节点）

左进右出 — 数据从左向右流动

+---------------------------------------------------------------------+
|  [色条] [图标]  YOLO 检测 v2                        [菜单按钮]       |  ← 顶部3px色条 + 标题
+------------+--------------------------------+------------------------+
|            |                                |                        |
|  ● image   |  model:  [yolov8n.pt   ▼]  |  ● image               |
|  ● trigger |  conf:   [====●====] 0.5   |  ● bboxes               |
|            |  iou:    [====●====] 0.45  |  ● scores               |
|            |  max_d:  [____300____]      |  ● categories           |
|            |  device: [auto       ▼]     |  ● count                |
|            |                                |                        |
+------------+--------------------------------+------------------------+
|  ⚙️ yolov8n.pt | conf: 0.50 | iou: 0.45 | 5 objs                 |  ← 底部摘要
+---------------------------------------------------------------------+

设计要点：

  • 顶部 3px 色条 — 类别标识（绿:input / 青:detection / 黄:processing / 橙:action / 紫:logic / 红:output）
  • 标题栏 — 图标 + 显示名 + 菜单按钮
  • 左侧 — INPUT 端口（接收上游数据）
  • 中间 — 配置控件（slider / dropdown / text / checkbox 等）
  • 右侧 — OUTPUT 端口（流向下游）
  • 底部 — 关键配置摘要（一眼能看到最重要参数）

2.2 节点端口规则

不是所有节点都有进有出，按类型区分：

节点类型INPUT端口OUTPUT端口例子
INPUT✗✓ImageCapture / VideoCapture
TRIGGER✗✓Timer / Webhook
PROCESSING✓✓YOLO / Resize / Filter
ACTION✓可选Notification / Save
LOGIC✓✓Condition / Delay
OUTPUT✓✗Log（纯终端）

实际端口数量完全由 definition.inputs / definition.outputs 决定，前端按需渲染。

5.3 前后端同步

  1. 前端从 GET /api/rule-engine/nodes/definitions 获取 config_schema
  2. 前端编辑 config，实时更新节点 data
  3. 通过 PUT /api/rule-engine/graphs/{id} 保存完整图
  4. 后端执行时从图数据读取 config

7.4 变量绑定表达式语法

变量引用格式：

{{variable_name}}           # 引用简单变量

{{array[index]}}            # 引用数组元素
{{object.property.nested}}  # 深层属性访问

内置变量：

变量名类型说明
$nowdatetime当前时间戳
$graph.idnumber当前规则图 ID
$execution.idnumber当前执行记录 ID

表达式引擎要求：

  • 使用 JavaScript 表达式语法
  • 支持基本数学运算：+, -, *, /, %

  • 支持三元运算符：condition ? true_val : false_val
  • 支持括号分组：(a + b) * c

7.5 执行状态机

节点状态：

┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│  idle   │ ──> │ running │ ──> │ success │ ──> │  idle   │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
     │               │               │
     │               │               │
     v               v               v
┌─────────────────────────────────────────┐
│                  failed                  │
└─────────────────────────────────────────┘
状态说明触发条件
idle空闲/等待执行初始状态 / 执行完成后重置
running执行中节点开始处理
success执行成功节点正常完成
failed执行失败节点处理出错
