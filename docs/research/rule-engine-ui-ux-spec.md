# 规则引擎画布编辑器 - UI/UX 交互规范

> 文档版本：v1.0
> 创建时间：2026-05-06
> 状态：规范制定

---

## 1. 概述

本文档定义 CogniFlow 规则引擎画布编辑器的 UI/UX 交互规范，确保一致的用户体验。

### 1.1 目标

- 提供清晰、完整的交互行为定义
- 确保团队成员实现一致的界面行为
- 减少用户学习成本，提高效率

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **一致性** | 相似功能使用相似的交互方式 |
| **即时反馈** | 每一个操作都有明确的视觉反馈 |
| **可逆性** | 支持撤销/重做，让用户放心尝试 |
| **直观性** | 无需阅读文档也能理解基本操作 |

## 4. 节点交互规范

### 4.1 节点状态视觉反馈

| 状态 | 边框颜色 | 背景色 | 动画 | 图标 |
|------|---------|--------|------|------|
| **默认** | `#4a4a4a` | `#2d2d2d` | 无 | 无 |
| **悬停** | `#6a6a6a` | `#333333` | 0.15s 过渡 | 无 |
| **选中** | `#00d4ff` (2px) | `#2d2d2d` | 外发光 `0 0 8px rgba(0,212,255,0.4)` | 选中手柄 |
| **运行中** | `#00d4ff` | `rgba(0,212,255,0.1)` | 边框脉冲动画 1.5s | 右上角旋转图标 |
| **执行完成** | `#4cff4c` (短暂) | `rgba(76,255,76,0.1)` | 0.3s 绿色闪烁 | 右上角勾号 |
| **错误** | `#ff4c4c` | `rgba(255,76,76,0.1)` | 无 | 右上角错误图标 |
| **禁用** | `#3a3a3a` | `rgba(61,61,61,0.5)` | 无 | 半透明 |

### 4.2 节点执行状态动画

```css
/* 运行中节点脉冲动画 */
.node.running {
  animation: node-pulse 1.5s ease-in-out infinite;
  border-color: #00d4ff;
}

@keyframes node-pulse {
  0%, 100% { box-shadow: 0 0 4px rgba(0, 212, 255, 0.4); }
  50% { box-shadow: 0 0 16px rgba(0, 212, 255, 0.8); }
}

/* 执行完成闪烁 */
.node.executed {
  animation: node-success 0.3s ease-out;
  border-color: #4cff4c;
}

@keyframes node-success {
  0% { background: rgba(76, 255, 76, 0.3); }
  100% { background: var(--bg-node); }
}
```

### 4.3 节点拖拽行为

| 阶段 | 行为 |
|------|------|
| **拖拽开始** | 节点透明度降至 0.7，添加阴影提升效果 |
| **拖拽中** | 显示节点预览，跟随鼠标移动 |
| **拖拽结束** | 节点放置到有效位置，触发历史记录保存 |
| **无效放置** | 节点返回原位置，显示 toast 提示 |

### 4.4 节点操作

| 操作 | 触发方式 | 结果 |
|------|---------|------|
| 选中节点 | 单击 | 选中节点，打开属性面板 |
| 添加节点 | 拖拽/双击节点面板 | 在画布中央或鼠标位置添加节点 |
| 移动节点 | 拖拽节点 | 节点跟随移动 |
| 删除节点 | `Delete` / `Backspace` / 按钮 | 删除节点及其连接边 |
| 复制节点 | `Ctrl + C` | 复制到剪贴板 |
| 粘贴节点 | `Ctrl + V` | 在画布偏移位置粘贴 |
| 全选 | `Ctrl + A` | 选中所有节点 |

## 5. 连线交互规范

### 5.1 连线类型与样式

| 类型 | 样式 | 适用场景 |
|------|------|---------|
| **数据流** | 贝塞尔曲线，默认青色 | 常规数据传递 |
| **条件分支** | 贝塞尔曲线，绿色(TRUE)/红色(FALSE) | 条件判断分支 |
| **执行流** | 虚线动画 | 触发器到首个节点 |
| **错误流** | 红色虚线 | 异常/错误传递 |

### 5.2 连线状态视觉反馈

| 状态 | 颜色 | 宽度 | 动画 |
|------|------|------|------|
| **默认** | `#4a4a4a` | 2px | 无 |
| **悬停** | `#6a6a6a` | 3px | 无 |
| **选中** | `#00d4ff` | 3px | 无 |
| **运行中** | `#00d4ff` | 2px | 虚线流动动画 `→ → →` |
| **类型不匹配** | `#ff4c4c` | 2px | 无 |
| **错误** | `#ff4c4c` | 3px | 红色脉冲 |

### 5.3 连线创建交互

| 阶段 | 行为 |
|------|------|
| **开始拖拽** | 从源端口显示临时连接线，跟随鼠标 |
| **悬停目标端口** | 目标端口高亮，临时线变成目标颜色 |
| **类型匹配** | 允许连接，临时线为正常颜色 |
| **类型不匹配** | 禁止连接，临时线变红 |
| **完成连接** | 创建正式连线，触发历史记录保存 |
| **取消连接** | 按 `Escape` 或拖离画布区域 |

### 5.4 类型匹配高亮

```typescript
// 类型匹配时目标端口高亮
const highlightValidTarget = (sourceType: string, targetPort: HTMLElement) => {
  targetPort.classList.add('valid-target');
  targetPort.style.borderColor = '#4cff4c';
  targetPort.style.boxShadow = '0 0 8px rgba(76, 255, 76, 0.5)';
};

// 类型不匹配时目标端口警告
const highlightInvalidTarget = (targetPort: HTMLElement) => {
  targetPort.classList.add('invalid-target');
  targetPort.style.borderColor = '#ff4c4c';
  targetPort.style.boxShadow = '0 0 8px rgba(255, 76, 76, 0.5)';
};
```

### 5.5 连线操作

| 操作 | 触发方式 | 结果 |
|------|---------|------|
| 创建连接 | 从端口拖拽到目标端口 | 创建连线 |
| 删除连接 | 选中边 + `Delete` / 右键删除 | 删除连线 |
| 断开连接 | 从端口拖离 | 删除连线 |

## 10. 执行状态规范

### 10.1 执行流程视觉反馈

```
1. 点击"执行"按钮
   → 按钮变为"执行中..."状态
   → 画布进入只读模式（禁止编辑）

2. 按拓扑顺序逐节点执行
   → 当前执行节点显示脉冲动画
   → 完成的节点显示绿色勾号
   → 失败的节点显示红色错误图标

3. 执行完成
   → 所有节点恢复正常状态
   → 显示执行结果 toast
   → 画布恢复编辑模式
```

### 10.2 执行日志面板

执行过程中可展开底部日志面板：

```

│ [控制: 暂停] [停止] [清空]                           [收起 v]   │
```

## 11. Toast 通知规范

### 11.1 Toast 类型

| 类型 | 颜色 | 图标 | 用途 |
|------|------|------|------|
| **success** | `#4cff4c` | ✓ | 操作成功 |
| **error** | `#ff4c4c` | ✗ | 操作失败 |
| **warning** | `#ffff4c` | ⚠ | 警告提示 |
| **info** | `#00d4ff` | ℹ | 信息提示 |

### 11.2 Toast 行为

| 行为 | 规范 |
|------|------|
| 显示位置 | 右上角，距顶部 80px |
| 显示时长 | 3 秒（可配置） |
| 堆叠 | 最多显示 3 条，新消息在上方 |
| 关闭 | 点击关闭按钮或 3 秒后自动消失 |
| 动画 | 从右侧滑入，1.5s 后淡出 |

## 12. 错误处理规范

### 12.1 错误类型与处理

| 错误类型 | 用户反馈 | 画布行为 |
|---------|---------|---------|
| 节点配置错误 | Toast + 属性面板高亮错误字段 | 节点显示警告图标 |
| 连接类型错误 | Toast 提示"类型不匹配" | 禁止创建连接 |
| 执行超时 | Toast + 日志面板显示错误 | 节点显示错误状态 |
| 保存失败 | Toast "保存失败" | 保持编辑状态 |
| 加载失败 | Toast "加载失败" | 显示空画布 |

### 12.2 空状态处理

| 场景 | 提示文案 | 操作引导 |
|------|---------|---------|
| 空画布 | "将节点从左侧拖入画布开始创建规则" | 显示引导动画 |
| 无选中节点 | "选择节点查看属性" | - |
| 搜索无结果 | "未找到匹配的节点" | 清除搜索 |
