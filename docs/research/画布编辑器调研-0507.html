4.3 视口裁剪实现

function getVisibleNodes(viewport, allNodes) {
  const { x, y, width, height, scale } = viewport;
  return allNodes.filter(node => {
    const [nx, ny] = node.position;
    const [nw, nh] = node.size || [200, 100];
    return (
      nx + nw > x / scale &&
      nx < (x + width) / scale &&
      ny + nh > y / scale &&
      ny < (y + height) / scale
    );
  });
}
// 效果：大型图（500+ 节点）可减少 99% DOM 操作

五、执行引擎

5.1 Kahn 算法拓扑排序

def topological_sort(nodes, edges):
    in_degree = {n: 0 for n in nodes}
    adj_list = {n: [] for n in nodes}
    for src, tgt in edges:
        in_degree[tgt] += 1
        adj_list[src].append(tgt)
    queue = [n for n in nodes if in_degree[n] == 0]
    result = []
    while queue:
        node = queue.pop(0)
        result.append(node)
        for neighbor in adj_list[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    return result

六、ComfyUI 专项调研

6.1 ComfyUI 前端架构

技术栈（重要发现）：

  • 渲染引擎：自研 Canvas 实现（非 React Flow / Vue Flow）
  • 原因：完全控制性能、避免虚拟 DOM 开销、特殊交互需求
  • 这与 CogniFlow 的需求高度匹配！

6.2 ComfyUI 后端 API

端点方法功能
/api/promptPOST提交工作流执行
/api/queueGET获取队列状态
/api/historyGET获取执行历史
/api/viewGET获取图片/结果
/api/system_statsGET系统状态

6.3 执行流程

客户端 POST /api/prompt
  → 服务器入队
  → WebSocket 推送 "executing"
  → 执行节点（拓扑排序 + 并行）
  → WebSocket 推送进度
  → 执行完成，WebSocket 推送 "executed"
  → 客户端获取结果 /api/view
